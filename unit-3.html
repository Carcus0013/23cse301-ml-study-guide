K-means: initial centroids, assignment, update, convergence

Very importantIn your materialsClustering (2).pdf

Question 6(a) of October 2025.

Concept

Clustering is unsupervised: group points so that points in the same cluster are more similar to each other than to points in other clusters. Your notes distinguish hard clustering (each point in exactly one cluster) from soft clustering (membership probabilities), and four model families: connectivity (hierarchical), centroid (K-means), distribution (Gaussian mixtures/EM) and density (DBSCAN).

K-means is the standard centroid method. It partitions n points into K clusters by minimising the within-cluster sum of squares (WCSS).

  1. Choose K and initial centroids (given, random points, or K-means++).
  2. Assignment: compute the distance from every point to every centroid; assign each point to the nearest.
  3. Update: recompute each centroid as the mean of the points assigned to it.
  4. Convergence: repeat 2–3 until no point changes cluster (centroids stop moving) or a maximum number of iterations.
Centroid: c_k = (1/|C_k|) Σ_{x ∈ C_k} x
Objective: WCSS = Σ_k Σ_{x ∈ C_k} ‖x − c_k‖²
Each assignment and each update can only lower WCSS, so K-means always converges — but to a local minimum that depends on the initial centroids. Weaknesses: K must be chosen in advance; sensitive to outliers and scaling; assumes roughly spherical, similar-sized clusters.

Common mistakes
  • Updating the centroid after each single assignment when the question expects batch updates.
  • Running more iterations than asked ("one iteration only" in Q6a).
  • Using Manhattan distance when the method uses Euclidean (or vice versa) without saying so.
Quick revision

Choose K, seeds → assign to nearest centroid → recompute means → repeat until stable. Minimises WCSS; local optimum; sensitive to K, seeds, outliers, scale.

Elbow method, WCSS and cluster evaluation

ImportantIn your materialsClustering (2).pdf

An easy add-on to any K-means numerical.

Concept

K-means needs K in advance. WCSS (within-cluster sum of squares, also "inertia") measures compactness; it always decreases as K grows (K = n gives 0), so we cannot simply minimise it. The elbow method: compute WCSS for K = 1, 2, 3, …, plot it, and choose the K where the curve bends — after which extra clusters give only small improvements.

WCSS(K) = Σ_k Σ_{x ∈ C_k} ‖x − c_k‖²
Silhouette of point i: s(i) = (b(i) − a(i)) / max(a(i), b(i))
a(i) = mean distance to the other points of its own cluster; b(i) = mean distance to the points of the nearest other cluster. s ranges −1 to 1: near 1 well clustered, 0 on a border, negative probably misassigned. Average silhouette over all points evaluates a clustering; pick K with the highest average. Other measures: Davies–Bouldin index (lower is better); with true labels, purity or adjusted Rand index.
Example 1 · BasicSource: practice problem on October 2025 Q6(a)'s result

Compute the WCSS of the Q6(a) clustering: {P1 (1,7), P4 (2,8)} with centroid (1.5, 7.5); {P2 (5,8), P5 (6,7)} with (5.5, 7.5); {P3 (1,1), P6 (2,2)} with (1.5, 1.5).

Each point is ±0.5 from its centroid in both coordinates: ‖x − c‖² = 0.5² + 0.5² = 0.5 for every point WCSS = 6 × 0.5 = 3.0

WCSS = 3.0.

Example 2 · IntermediateSource: practice problem

Seven points (1,1), (1.5,2), (3,4), (5,7), (3.5,5), (4.5,5), (3.5,4.5). The best K-means solutions give WCSS = 37.07 (K = 1), 8.53 (K = 2), 2.50 (K = 3), 1.29 (K = 4). Verify the K = 2 value and choose K by the elbow method.

K = 2: clusters {(1,1), (1.5,2)} and the other five c₁ = (1.25, 1.5): (0.0625 + 0.25) × 2 = 0.625 c₂ = (19.5/5, 25.5/5) = (3.9, 5.1): (3,4): 0.81 + 1.21 = 2.02 (5,7): 1.21 + 3.61 = 4.82 (3.5,5): 0.16 + 0.01 = 0.17 (4.5,5): 0.36 + 0.01 = 0.37 (3.5,4.5): 0.16 + 0.36 = 0.52 → 7.90 WCSS = 0.625 + 7.90 = 8.525 ✓ Drops: K 1→2: 28.5; 2→3: 6.0; 3→4: 1.2

Choose K = 2: going from 1 to 2 clusters removes 77% of the WCSS; later clusters add little (K = 3 is a defensible second choice).

Example 3 · Exam levelSource: practice problem

Clusters A = {a (1,1), b (1,2), c (2,1)} and B = {d (6,6), e (7,6)}. Compute the silhouette of point a and interpret. Why is the elbow method alone sometimes not enough?

a(a) = [d(a,b) + d(a,c)]/2 = (1 + 1)/2 = 1 b(a) = [d(a,d) + d(a,e)]/2 = (√50 + √61)/2 = (7.071 + 7.810)/2 = 7.441 s(a) = (7.441 − 1)/7.441 = 0.866

s(a) = 0.87: a sits comfortably inside its own cluster, far from the other.

The elbow is often not sharp (WCSS can fall smoothly), and WCSS ignores separation between clusters. The silhouette uses both cohesion (a) and separation (b), so it gives a second, more objective opinion on K.

Common mistakes
  • Choosing the K with the smallest WCSS (always the largest K).
  • Using distances instead of squared distances in WCSS.
Quick revision

WCSS = Σ‖x − c‖²; decreases with K. Elbow = bend in the WCSS-vs-K plot. Silhouette s = (b − a)/max(a, b), closer to 1 is better.

Hierarchical clustering: agglomerative, divisive, linkages, dendrograms

Very importantIn your materialsclustering.pdf · hierarchical_clustering_solution.pdf · Clustering (2).pdf

Question 6(b) of October 2025.

Concept

Hierarchical clustering builds a tree of nested clusters instead of one flat partition, so K need not be fixed in advance.

  • Agglomerative (bottom-up): start with every point as its own cluster; repeatedly merge the two closest clusters until one remains.
  • Divisive (top-down): start with one cluster of all points; repeatedly split until every point is alone.

A dendrogram records the merges: leaves are points, each join is drawn at the height (distance) at which the merge happened. Cutting the dendrogram horizontally at some height gives a flat clustering — the number of vertical lines cut is the number of clusters.

Single linkage: D(A, B) = min_{a∈A, b∈B} d(a, b) (closest pair)
Complete linkage: D(A, B) = max_{a∈A, b∈B} d(a, b) (farthest pair)
Average linkage: D(A, B) = (1/(|A||B|)) Σ_a Σ_b d(a, b) (mean of all pairs)
Ward: merge the pair that least increases total WCSS (topic 46)

Agglomerative algorithm

  1. Compute the n × n distance matrix (symmetric, zero diagonal).
  2. Find the smallest off-diagonal entry; merge those two clusters; record the height.
  3. Update the matrix: replace the two rows/columns with one, using the linkage rule.
  4. Repeat until one cluster remains; draw the dendrogram.

46

Ward's method

AdditionalPartialentire_Machine Learning.pptx (named)

Named once in your materials; the arithmetic is heavier than the other linkages, so expect theory or a small case.

Concept

Ward's minimum-variance method is an agglomerative linkage that, at each step, merges the two clusters whose union causes the smallest increase in total within-cluster sum of squares (WCSS) — the same quantity K-means minimises. It tends to produce compact, similar-sized, roughly spherical clusters.

Merge cost: Δ(A, B) = SSE(A ∪ B) − SSE(A) − SSE(B) = (n_A n_B / (n_A + n_B)) · ‖c_A − c_B‖²
c_A, c_B = centroids, n_A, n_B = sizes. Two single points cost d²/2. Because it uses centroids and squared Euclidean distance, Ward needs numeric features and Euclidean geometry.
Example 1 · BasicSource: practice problem

Cluster A = {(1,1), (2,1)}, B = {(5,4), (6,5)}, C = {(1,3)}. Which pair does Ward merge next?

c_A = (1.5, 1), c_B = (5.5, 4.5), c_C = (1, 3) Δ(A,B) = (2·2/4) × [(4)² + (3.5)²] = 1 × (16 + 12.25) = 28.25 Δ(A,C) = (2·1/3) × [(0.5)² + (2)²] = 0.667 × 4.25 = 2.833 Δ(B,C) = (2·1/3) × [(4.5)² + (1.5)²] = 0.667 × 22.5 = 15.0

Merge A and C (smallest increase, 2.833).

Example 2 · IntermediateSource: practice problem

Verify the Example 1 cost directly: compute SSE(A), SSE(C) and SSE(A ∪ C).

SSE(A) = (1 − 1.5)² + (2 − 1.5)² + 0 + 0 = 0.5; SSE(C) = 0 A ∪ C = {(1,1), (2,1), (1,3)} → centroid (4/3, 5/3) SSE = [(1/3)² + (2/3)²] + [(2/3)² + (2/3)²] + [(1/3)² + (4/3)²] = 5/9 + 8/9 + 17/9 = 30/9 = 3.333 Increase = 3.333 − 0.5 − 0 = 2.833 ✓

The shortcut formula and the direct calculation agree: Δ = 2.833.

Example 3 · Exam levelSource: practice problem

Cluster {1, 2, 6, 7, 15} with Ward's method; give the merge heights and compare with single linkage.

Ward (cost = n_A n_B/(n_A+n_B) × (mean difference)²): {1}+{2}: ½ × 1 = 0.5 {6}+{7}: ½ × 1 = 0.5 (merge both) {1,2}+{6,7}: (2·2/4)(1.5 − 6.5)² = 1 × 25 = 25 {6,7}+{15}: (2·1/3)(6.5 − 15)² = 0.667 × 72.25 = 48.2 {1,2}+{15}: 0.667 × 13.5² = 121.5 → merge {1,2,6,7} at 25 {1,2,6,7}+{15}: (4·1/5)(4 − 15)² = 0.8 × 121 = 96.8 Single linkage: {1,2} at 1, {6,7} at 1, {1,2}+{6,7} at 4 (|2 − 6|), +{15} at 8 (|7 − 15|)

Common mistakes
  • Forgetting the size factor n_A n_B/(n_A + n_B).
  • Using unsquared distances.
Quick revision

Ward merges the pair with the smallest increase in WCSS: Δ = (n_A n_B/(n_A+n_B))‖c_A − c_B‖². Compact, balanced clusters; Euclidean only.

Base, weak and strong learners; meta-model; voting and averaging

Very importantIn your materialsEnsemble_Learning_PowerPoint_Compatible.pptx · Regression.pdf

Question 4(a) of October 2025.

Concept

Ensemble learning trains several models and combines their outputs, because "a single model may overfit, underfit, or make unstable predictions" (your ensemble deck). If the models make different, partly independent mistakes, combining them cancels many of those mistakes — the "wisdom of crowds".

  • Base learner: each individual model inside the ensemble (e.g. each decision tree in a Random Forest).
  • Weak learner: a model only slightly better than random guessing (accuracy just above 50% for two classes), e.g. a decision stump (one-split tree).
  • Strong learner: a model with high accuracy; boosting proves that many weak learners can be combined into a strong one.
  • Meta-model (combiner): the rule or model that combines base-learner outputs — majority vote, weighted vote, averaging, or a trained model in stacking.
Hard (majority) voting: ŷ = mode{h₁(x), …, h_M(x)}
Soft voting: ŷ = argmax_c (1/M) Σ_m P_m(c | x)
Weighted voting: ŷ = argmax_c Σ_m w_m · [h_m(x) = c]
Averaging (regression): ŷ = (1/M) Σ_m h_m(x)
Majority of M independent classifiers each with accuracy p: P(correct) = Σ_{k > M/2} C(M,k) p^k (1−p)^(M−k)

Bagging: bootstrap sampling, parallel training, aggregation, variance

ImportantIn your materialsEnsemble_Learning_PowerPoint_Compatible.pptx · Regression.pdf

The standard comparison partner of boosting.

Concept

Bagging = Bootstrap AGGregatING (Breiman, 1996).

  1. Bootstrap sampling: from the n training rows draw B samples of size n with replacement. Each sample repeats some rows and leaves others out.
  2. Parallel training: train one base model (usually a deep, unpruned tree) on each sample, independently — they can run at the same time.
  3. Aggregation: majority vote (classification) or average (regression).

Rows not drawn into a model's sample are its out-of-bag (OOB) rows; predicting each row with only the models that did not see it gives a free validation estimate.

P(a given row is never drawn) = (1 − 1/n)ⁿ → e^(−1) = 0.368 as n grows
So each bootstrap sample contains ≈ 63.2% distinct rows
Variance of the average of B models, each variance σ², pairwise correlation ρ: ρσ² + (1 − ρ)σ²/B
Averaging reduces variance but leaves bias unchanged, so bagging helps unstable, high-variance learners (deep trees) and does little for stable ones (linear regression, KNN with large K).

Random Forest: bootstrap rows, random features, majority vote

Very importantIn your materialsEnsemble_Learning_PowerPoint_Compatible.pptx · Regression.pdf · Classification.pdf

Question 4(a) of October 2025.

Concept

A Random Forest is bagging with decision trees plus one extra source of randomness. Your deck: "randomness is added in two places: rows and features".

  1. For each of B trees, draw a bootstrap sample of the rows.
  2. Grow a deep decision tree on it; at every split, consider only a random subset of m features (typically m = √p for classification, p/3 for regression) and choose the best split among them.
  3. Do not prune.
  4. Predict by majority vote (classification) or averaging (regression).

Why random features? If one feature is very strong, every bagged tree would split on it first and the trees would be highly correlated (Regression.pdf: "each tree in a random forest can pick only from a random subset of features … forces even more variation"). Uncorrelated trees "protect each other from their individual errors".

Boosting and AdaBoost: error, α, weight update, normalization, final prediction

Very importantIn your materialsEnsemble_Learning_PowerPoint_Compatible.pptx

Question 4(b) of October 2025 (4 marks).

Concept

Boosting trains weak learners sequentially; each new learner concentrates on the samples the previous ones got wrong ("misclassified samples get higher weight in the next round"). AdaBoost (Adaptive Boosting, Freund & Schapire 1997) does this with sample weights.

  1. Initialise weights wᵢ = 1/n for all n samples.
  2. For t = 1 … T:
    1. Train a weak learner h_t (often a decision stump) on the weighted data.
    2. Weighted error ε_t = Σ wᵢ over misclassified samples.
    3. Classifier weight α_t = ½ ln((1 − ε_t)/ε_t).
    4. Update: wᵢ ← wᵢ · e^(−α_t) if correct, wᵢ · e^(+α_t) if wrong.
    5. Normalise: divide every weight by Z_t = Σ (updated weights) so they sum to 1.
  3. Final prediction: H(x) = sign( Σ_t α_t h_t(x) ).
α = ½ ln((1 − ε)/ε) ε = 0.5 → α = 0; ε → 0 → α large; ε > 0.5 → α < 0
wᵢ ← wᵢ · e^(−α yᵢ h(xᵢ)) / Z (yᵢh(xᵢ) = +1 if correct, −1 if wrong)
After normalising, the misclassified samples always carry exactly half the total weight.

Exploration vs exploitation; applications

ImportantIn your materials23CSE301_ML_RL.pdf (§6)

A short-answer staple of RL questions.

Concept

An agent learns the value only of actions it tries. Exploitation means choosing the action that currently looks best; exploration means trying other actions to improve its estimates. Pure exploitation can get stuck on a mediocre action whose rivals were never sampled properly; pure exploration never uses what it has learned (your RL module). The simplest model is the multi-armed bandit: k slot machines with unknown payouts.

ε-greedy: with probability 1 − ε take argmax_a Q(a); with probability ε take a uniformly random action
⇒ P(greedy action) = 1 − ε + ε/k, P(each other action) = ε/k
Incremental sample average: Q_n = Q_{n−1} + (1/n)(R_n − Q_{n−1})
UCB (upper confidence bound): choose argmax_a [ Q(a) + c √(ln t / N(a)) ]
Softmax (Boltzmann): P(a) = e^(Q(a)/τ) / Σ_b e^(Q(b)/τ)
ε is often decayed (start near 1, end near 0): explore early, exploit later. UCB adds a bonus to rarely tried actions — "optimism in the face of uncertainty". Reference: Sutton & Barto, Reinforcement Learning: An Introduction, 2nd ed., Ch. 2, incompleteideas.net/book/the-book-2nd.html.

Everyday analogy: always ordering your favourite dish (exploit) versus trying a new one that might be better (explore).

Example 1 · BasicSource: practice problem

An agent has k = 4 actions and uses ε-greedy with ε = 0.1. What is the probability of choosing the greedy action and each non-greedy action?

P(greedy) = 1 − 0.1 + 0.1/4 = 0.9 + 0.025 = 0.925 P(each other) = 0.1/4 = 0.025 Check: 0.925 + 3(0.025) = 1 ✓

0.925 for the greedy action, 0.025 for each of the other three.

The random choice can land on the greedy action too, which is why it gets 0.925, not 0.9.

Example 2 · IntermediateSource: practice problem (method from Sutton & Barto, §2.4)

An arm is pulled four times with rewards 4, 6, 5, 9. Update its estimate Q incrementally after each pull, starting from Q₀ = 0.

n=1: Q = 0 + (1/1)(4 − 0) = 4 n=2: Q = 4 + (1/2)(6 − 4) = 5 n=3: Q = 5 + (1/3)(5 − 5) = 5 n=4: Q = 5 + (1/4)(9 − 5) = 6

Q = 4, 5, 5, 6 — the running mean of the rewards (24/4 = 6), computed without storing them.

The form "new = old + step × (target − old)" is the same shape as the Q-learning update in topic 51.

Example 3 · Exam levelSource: practice problem (UCB from Sutton & Barto, §2.7)

After t = 15 pulls, three arms have estimates Q = (0.8, 0.6, 0.5) from N = (10, 3, 2) pulls. (i) Which arm does a greedy agent choose? (ii) Which does UCB with c = 2 choose? (iii) Explain the difference and give two real applications of this trade-off.

ln 15 = 2.708 Arm 1: 0.8 + 2√(2.708/10) = 0.8 + 2(0.5204) = 1.841 Arm 2: 0.6 + 2√(2.708/3) = 0.6 + 2(0.9501) = 2.500 Arm 3: 0.5 + 2√(2.708/2) = 0.5 + 2(1.1636) = 2.827

(i) Greedy picks arm 1 (highest Q = 0.8). (ii) UCB picks arm 3 (2.827).

Arm 3 has been tried only twice, so its estimate is very uncertain; UCB's bonus rewards that uncertainty, so it explores arm 3 before committing to arm 1. As N grows the bonus shrinks and UCB settles on the truly best arm. Applications: A/B testing of web pages or ads (try new versions vs show the current best), clinical trial allocation, recommendation systems (suggest familiar items vs new ones), game-playing agents.

Common mistakes
  • Writing P(greedy) = 1 − ε (forgetting the ε/k share).
  • Saying exploration is wasted effort; it is how the agent finds better actions.
Quick revision

Exploit = use best-known action; explore = try others to learn. ε-greedy: 1 − ε + ε/k for greedy. UCB = Q + c√(ln t/N). Decay ε over time. Bandits, A/B tests, recommendations.
