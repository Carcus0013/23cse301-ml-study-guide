Q1

ID3 decision tree

[6][CO04][BTL4]Unit IIFull solution: Topic 23 →

Build the ID3 tree that predicts whether a patient has the disease.

  • (a)Initial entropy of the dataset2 marks
  • (b)Best attribute for the root split2 marks
  • (c)State the splitting criterion1 mark
  • (d)Draw the final tree1 mark
Entropy(S) = −Σ pᵢ log₂ pᵢ  ·  Gain(S,A) = Entropy(S) − Σ (|Sᵥ|/|S|)·Entropy(Sᵥ)
MethodEntropy of S, then information gain for Fever, Cough and Fatigue. The largest gain becomes the root. Expand only the branches that are still impure.
WatchCheck each branch for purity before expanding. On this data the tree can stop after one split, and students lose time building levels that do not exist.

Q2

Regularization and KNN distance metrics

[6][CO04][BTL2]Unit IFull solution: Topics 15 & 18 →
  • (a)How increasing λ affects the bias–variance trade-off2 marks
  • (b)How Euclidean vs Manhattan distance changes KNN's result, with a 1–2 line scenario where one suits better4 marks
Euclidean d = √Σ(xᵢ−yᵢ)²  ·  Manhattan d = Σ|xᵢ−yᵢ|  ·  Minkowski d = (Σ|xᵢ−yᵢ|ᵖ)^(1/p)
MethodTheory, written precisely. Link λ to model complexity, then to bias and variance. For (b), explain that different metrics can rank neighbours differently and so change the vote.
WatchFour marks for an explanation means a concrete scenario is expected, such as grid-like city-block movement or high-dimensional data for Manhattan. Mention feature scaling too.

Q3

SVM: support vectors and the maximum marginal hyperplane

[8][CO04][BTL4]Unit IIFull solution: Topic 27 →
  • (a)What are support vectors?2 marks
  • (b)Design a linear SVM that finds the MMH for the two classes6 marks
Σⱼ αⱼ (s̃ⱼ · s̃ᵢ) = yᵢ  →  w̃ = Σ αᵢ s̃ᵢ  →  hyperplane w·x + b = 0
MethodThe course method (Classification.pdf, slides 137–143): plot the points, choose the support vectors, augment each with a bias input of 1, solve the α equations, form w̃, and read off w and b. Cross-check geometrically: the hyperplane sits midway between the closest opposite points.
WatchShow the plot. Examiners award marks for identifying the support vectors visually before any algebra.
Error in the paper The positive point (−2, −6) sits far below the negative class. With it, the shaded positive region contains the negative point (−1, 0), so no straight line separates the classes, even though the question says they are linearly separable. It was almost certainly meant to be (−2, 6). In the exam, state the correction in one line and solve with it.

Q4

Random Forest roles and AdaBoost weight update

[6][CO05][BTL3]Unit IIIFull solution: Topics 47 & 50 →
  • (a)Spam filter built as a Random Forest: name the base learner and the meta-model and how they combine2 marks
  • (b)New normalised weights for round 2 with ε = 0.33, and which samples gain influence4 marks
α = ½ ln((1 − ε)/ε)  ·  wᵢ ← wᵢ · e^(±α) / Z
MethodCompute α, multiply misclassified weights by e^(+α) and correct ones by e^(−α), add them up to get Z, then divide every weight by Z.
WatchThe sign is the usual slip: misclassified samples get e^(+α). Z is the sum of the un-normalised weights, not 1. Check the new weights add to 1. ε = 0.33 is the rounded value of 2/6; use the value given.

Q5

Logistic regression: odds and odds ratio

[6][CO03][BTL3]Unit IFull solution: Topic 17 →
  • (a)Odds of meeting targets for >40 h and ≤40 h groups2 marks
  • (b)Odds ratio (>40 h vs ≤40 h)2 marks
  • (c)Logistic regression model with hours (≤40 vs >40) as predictor2 marks
odds = p/(1−p) = met/not met  ·  OR = odds₁/odds₀  ·  ln(p/(1−p)) = β₀ + β₁x
MethodOdds come straight from the counts. Code x = 1 for >40 h and x = 0 for ≤40 h, so β₀ = ln(odds₀) and β₁ = ln(OR). Then write p = 1/(1 + e^−(β₀+β₁x)).
WatchOdds are not probabilities: 42/8, not 42/50. State the coding of x, or the model in (c) has no meaning.
Inconsistency in the paper The question says 50 employees, but the table adds up to 100. No answer changes, because odds use the counts within each row.

Q6

K-means and hierarchical clustering

[6][CO05][BTL4]Unit IIIFull solution: Topics 43 & 45 →
  • (a)One K-means iteration from C1 = [1,7], C2 = [5,8], C3 = [1,1]: clusters and updated centroids3 marks
  • (b)Agglomerative clustering, single linkage, Manhattan distance, with dendrogram3 marks
centroid = (mean of x, mean of y)  ·  single link D(A,B) = min d(a,b)  ·  d = |x₁−x₂| + |y₁−y₂|
Method(a) Distance table, point to each centre; assign each point to its nearest centre; average each group. (b) Manhattan distance matrix; merge the closest pair; update distances with the minimum; repeat; draw the merges at their heights.
WatchOne iteration only in (a). In (b) the paper asks for Manhattan, not Euclidean, and single linkage uses the closest pair of points, not the centroids.

Q7

Hidden Markov Model and Markov chain

[6][CO04][BTL3]Unit IIFull solution: Topics 32 & 33 →
  • (a)Speech recognition as an HMM: hidden states, observations, how they relate2 marks
  • (b)Probability of the sequence {Sunny, Cloudy, Rainy, Rainy}, and interpret it4 marks
P(q₁, q₂, …, q_T) = π(q₁) · a(q₁→q₂) · a(q₂→q₃) · … · a(q_{T−1}→q_T)
Method(a) Hidden states are the phonemes or words; observations are the acoustic feature vectors; emission probabilities link them. (b) Start probability times one transition for each step, read row → column from the matrix.
WatchDo not drop π(Sunny). Read the matrix as from-row to-column. This is a plain Markov chain, so there are no emission probabilities in (b). A small answer is expected; say what it means.

Q8

Perceptron for the NAND gate

[6][CO04][BTL4]Unit IIFull solution: Topic 37 →
  • (a)First iteration: net input y and output o for all four patterns3 marks
  • (b)Which pattern, if any, is misclassified1 mark
  • (c)Apply the update rule and give the new weights and bias2 marks
y = w₁x₁ + w₂x₂ + b  ·  o = 1 if y ≥ 0 else 0  ·  wᵢ ← wᵢ + η(t − o)xᵢ,  b ← b + η(t − o)
MethodTabulate x₁, x₂, y, o and target t for all four rows. Compare o with t. Update only on the rows where they differ.
WatchThe activation fires at y ≥ 0, so a net input of exactly 0 gives output 1. When x₁ or x₂ is 0, its weight does not change. Update the bias too.
